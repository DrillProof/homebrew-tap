# DrillProof Homebrew tap

```sh
brew install drillproof/tap/audit
```

Installs `drillproof` — a read-only CLI that checks whether your AWS backups are
actually recoverable (EBS, RDS, EKS).

Source: <https://github.com/DrillProof/audit>
